## File 02_KK_TNCN_v2.1.6_mau.xls

### Sheet "01" (tờ khai + bảng tính thuế TNCN)
- [G3] [01] Kỳ tính thuế: "Quý <V47> (Từ tháng <M70> đến tháng <O70>) năm <V48>"
- [L4] Lần đầu = "[X]" nếu Header!V29 trống; [Q4]/[I70] Bổ sung lần thứ = V29
- [I5] [02] Tên người nộp thuế = TRIM(C3); [I6] [03] MST = nối 13 ô từ Header (ô trống để " ")
- [I7] Tên đại lý thuế (nếu có) = TRIM(V6); [I8] MST đại lý = TRIM(V5)
- [R45] [24] = R46 + R47 + R48 + R49 + R50 (tổng 5 dòng chi tiết)
- [AB46] = 9000000 × T70; [AB50] = 1000000 × T70 (ngưỡng thu nhập × hệ số T70, ô ẩn)
- [R51] [30] = nếu (R43 − R44 − R45 > 0) thì R43 − R44 − R45, khác thì 0
- [AD51] = R51 / T70 (thu nhập bình quân, ô ẩn)
- [AE51] Thuế TNCN theo bậc (ô ẩn): 0 nếu AD51 ≤ 0; nếu AD51 < 5000000 → AD51×5%; < 10000000 → AD51×10% − 250000; < 18000000 → ×15% − 750000; < 32000000 → ×20% − 1650000; < 52000000 → ×25% − 3250000; < 80000000 → ×30% − 5850000; khác → ×35% − 9850000; rồi ROUND(× T70, 0) — thuế TNCN lũy tiến 7 bậc
- [R54] [33] = nếu (R43 − R44 ≠ 0) thì ROUND(R52 × (R53/(R43−R44)) × 0,5, 0), khác thì 0
- [R55] [34] = ROUND(R52 − R54, 0)
- [R59]/[AB59] [37] = ROUND(R57 × R58 / 100, 0); [R63]/[AD63] [38] = ROUND(R61 × R62 / 100, 0)
- [H66] Họ và tên = TRIM(V15); [R66] Người ký = TRIM(V41); [H68] Chứng chỉ = TRIM(V16); [R68] Ngày ký = V42 (trống → "")
- [C70] Cờ "Chính thức" = "1" nếu V29 trống; [F70] Cờ "Bổ sung" = "1" nếu V29 có giá trị
- [M70] Từ tháng = TRIM(V34); [O70] Đến tháng = TRIM(V35)

### Sheet "KHBS" (bảng khấu trừ)
- [B6] STT = B5 + 1; [G6] Cột 0 = F6 − E6
- [E8]/[F8]/[G8] Tổng cộng = SUM(E5:E7) / SUM(F5:F7) / SUM(G5:G7)

### Sheet "Header"
- [M2] ký hiệu MST (3 ô N2..P2 trống → " ", khác → " - "); [T8] "nguoi ky" = CONCATENATE(1)
- Nhóm cờ kiểm tra (B = 0/1, C = giá trị tham chiếu): [B15] 01!R50 ≤ 01!AB50; [B18] 01!R53 ≤ 01!R43; [B21] có ngày ký (độ dài 01!R68 > 0); [B22] có họ tên nhưng thiếu chứng chỉ (H66 có, H68 thiếu); [B23] 01!R44 ≤ 01!R43
