## File 03_TBAC_BLP_v2.1.0_mau.xls

### Sheet "01" (thông báo chính)
- [H4] Tên cơ quan thu phí, lệ phí = TRIM(Header!C3)
- [H5] [Mã số thuế (nếu có)] = nối 13 ô từ Header (ô trống để " ")
- [AA43] Số lượng trong khoảng = nếu (V43 hoặc Y43 trống) thì 0, khác thì nếu (Y43 − V43 > 0) thì Y43 − V43 + 1, khác thì 0 — đếm số biên lai từ V43 (từ số) đến Y43 (đến số)
- [AE43] Cờ "Kiểm tra số lượng" = 1 nếu AA43 ≤ 0, khác thì 0
- [AF43] Cờ "Kiểm tra từ số" = 1 nếu V43 = 0, khác thì 0
- [AG43] Cờ "Kiểm tra đến số" = 1 nếu Y43 = 0, khác thì 0
- [R47] Thủ trưởng đơn vị = TRIM(Header!V41); [R49] Ngày lập thông báo = TRIM(Header!V42)

### Sheet "KHBS" (bảng khấu trừ)
- [B6] STT = B5 + 1; [G6] Cột 0 = F6 − E6
- [E8]/[F8]/[G8] Tổng cộng = SUM(E5:E7) / SUM(F5:F7) / SUM(G5:G7)

### Sheet "Header"
- [M2] ký hiệu MST (3 ô N2..P2 trống → " ", khác → " - "); [T8] "nguoi ky" = CONCATENATE(1)
