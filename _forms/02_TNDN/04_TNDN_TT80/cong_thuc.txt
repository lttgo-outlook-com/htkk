## File 04_TNDN_TT80_v2.5.1_mau.xls (template)

### Sheet "01" (tờ khai chính)
- [AH11] [01] kỳ tính thuế = IF(Header!V30 = "Y", "[X] Năm: "&Header!V48, "[X] Từng lần phát sinh ngày "&MID(V31)...) (năm hoặc từng lần, ngày format "d/m/y" từ MID)
- [AG15] [02] lần đầu = IF(Header!V29 = "", "X", ""); [BF15] [03] bổ sung lần thứ = IF(Header!V29 = "", "", Header!V29)
- [C21, F21, I21] cờ chính thức/bổ sung/lần = theo Header!V28
- [L21] cờ tờ khai = IF(Header!V29 = "Y", 1, IF("M", 2, IF("Q", 3, 4)))
- [O21, S21, X21] từ tháng/đến tháng/ngày phát sinh = Header!V33/V34/V31
- [AB21] tổ chức khai thay = TRIM(Header!V4)
- [V28] tên NNT = TRIM(Header!C3); [V30] MST tách ký tự; [V32] MST đại lý = TRIM(Header!V6); [V34] = TRIM(Header!V5)
- [P36] họ tên người ký = TRIM(Header!V13)
- [F38] ngày phát sinh = IF(O38 = "1", Header!V31, ""); [O38] cờ "từng lần" = IF(Header!V30 = "D", "1", "")
- [L38, M38] cờ lần đầu/bổ sung = IF(Header!V29 = "", "1"/"1", "")
- Khối tính thuế (cột BH, dòng 43-57):
  - [BH43] (4) = BH44+BH45+BH46 (tổng 3 dòng)
  - [BH51] (khối "cbo") = ROUND(BH44×BS48/100, 0)+ROUND(BH45×BH49/100, 0)+ROUND(BH46×BH50/100, 0) (thuế = giá trị × thuế suất % của từng dòng, làm tròn nguyên; dòng 1 dùng thuế suất BS48)
  - [BH53] = IF(BH51−BH52 > 0, BH51−BH52, 0) (chênh lệch dương, chặn dưới 0)
  - [BH56] = BH53−BH55; [BH57] = BH53−BH54−BH55 (tiếp trừ các khoản)
- [Q69] = TRIM(Header!V15); [Q71] = TRIM(Header!V16) (chứng chỉ); [BC69] người ký = TRIM(Header!V41); [BC71] ngày ký = IF(Header!V42 ≠ "", V42, "")
- [BX38, CG38] = SUM(#REF!) (ô tham chiếu hỏng, giữ nguyên)

### Sheet "04-2-MGT" (phụ lục MGT — phân bổ 70%/30%)
- [C4] "[01]  Kỳ tính thuế: "&01!AH11
- [E21] chỉ tiêu [10] (4) = E23+E24+E25 (tổng 3 dòng)
- [F21, F26] chỉ tiêu [10] = 01!I39+01!AH39 (lấy 2 ô tờ khai)
- [F23] chỉ tiêu [11] (phần 70%) = ROUND(01!CF39×70/100, 0)
- [E26] chỉ tiêu [14] (tổng phần 30%) = E28+E29+E30
- [E28, E29, E30] chỉ tiêu [15]/[16]/[17] (từng dòng, phần 30%) = ROUND(E23×30/100, 0) / ROUND(E24×30/100, 0) / ROUND(E25×30/100, 0)

### Sheet "01-KHBS" (khai bổ sung)
- [L6, L8, L10, L12, L14, L16] prefill từ '01-1-KHBS' (mã mẫu O6, mã giao dịch O8, kỳ O10, bổ sung O12, NNT O14, MST O16)
- [O36] tổng số thuế phải nộp = O49; [O37] tổng khấu trừ = O88; [O38] tổng đề nghị hoàn = O103
- [O49] [10] = SUM(O46:O48); [AF62] [11] = SUM(AF58:AI60); [O88] [12] = SUM(O85:O87); [O103] [13] = SUM(O100:O102)
- [M73] = U36 (ô tham chiếu); prefill đại lý (L18/L20) từ Header

### Sheet "01-1-KHBS" (bảng điều chỉnh)
- [O10] [03] kỳ tính thuế = 01!AH11; [O12] [04] bổ sung = 01!BF15; [O14] NNT = 01!V28; [O16] MST = 01!V34
- [Z46] (6) = (5)−(4) = V46−R46
- [AD46] (7) = IF(TRIM(BR46) ≠ "", Z46, 0) (chỉ lấy khi ô BR46 có chữ)
- [CB46, CC46, CD46] = IF(BV46 = 0/1/2, AD46, 0) (đẩy sang cột theo cờ BV46)
- [AD48, AD49, AD50] [07]/[08]/[09] = SUM(CB45:CB47) / SUM(CC45:CC47) / SUM(CD45:CD47)

### Sheet "Header"
- [M2] định dạng MST = IF(TRIM(N2&O2&P2) = "", " ", " - "); [T8] = CONCATENATE(1)
- Bộ cờ kiểm tra (0/1): [B25] = 1 nếu 01!BH52 ≤ 01!BH51 (C25 = giá trị BH52); [B26] = 1 nếu 01!BH49 ∈ {0, 1}; [B27] = 1 nếu 01!BH50 ∈ {0, 2}
